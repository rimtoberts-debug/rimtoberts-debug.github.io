Genetic Algorithms and
Network Architectures (HL)

Search for solutions by evolving a population, and meet the specialised neural network designs used for images, sequences and language.

🎓GCSE & A-Level✓Free🧩simulations + quiz
Hook

Nature solves hard design problems without a designer: animals that survive and reproduce pass on useful traits, with small random changes along the way.

Computer scientists borrowed that idea to search for good answers when there are far too many possibilities to try them all.

Think: What would happen to the search if every offspring were an exact copy of a parent, with no random changes at all?
Explanation

How a genetic algorithm works

A genetic algorithm (GA) keeps a population of candidate solutions, each encoded as a chromosome (a string of genes, such as numbers or bits). A fitness function scores how good each one is.

Repeat: select fitter individuals as parents, combine two parents with crossover (swapping parts of their chromosomes), apply mutation (random small changes), and form a new generation. Stop after a set number of generations or when fitness is good enough.

Selection pushes the population towards good solutions; crossover mixes good parts; mutation keeps variety so the search does not get stuck. Too little mutation stalls; too much turns the search into random guessing.

Explanation

Where genetic algorithms are used

GAs suit problems with a huge search space and a clear way to score a solution but no easy formula: timetabling, route planning, designing antenna shapes or circuits, and tuning the settings (hyperparameters) of other machine learning models. They do not guarantee the best answer, only a good one, and designing the fitness function and encoding well is the hard part.

Explanation

Neural network architectures (HL)

A feed-forward network passes data one way from input to output. A convolutional neural network (CNN) uses small shared kernels to detect local patterns such as edges, then builds up to shapes and objects, so it is the standard choice for images. Pooling layers shrink feature maps to keep the strongest signals.

A recurrent neural network (RNN) feeds its output back in, giving it a memory of earlier items in a sequence (text, audio, sensor readings). Variants such as LSTM cells cope better with long sequences. Transformers replace recurrence with attention and now dominate language tasks.

In every case, the number of layers and neurons, kernel sizes and learning rate are hyperparameters: settings chosen by the designer before training, as opposed to parameters (the weights) learned during training. Deeper, wider networks can learn more complex patterns but need more data and computing power and are more likely to overfit.

Activity

Put the stages in order.

Measure the fitness of each individual

Reflect

Questions worth thinking about

Zero mutation means no new variety can appear so the search can stall; too much destroys good solutions and becomes random search.
Shared kernels detect the same feature anywhere in the image with far fewer weights, and they exploit the fact that nearby pixels are related.
Summary

What to remember

  • A GA evolves a population using fitness, selection, crossover and mutation.
  • It finds good, not guaranteed best, solutions in huge search spaces.
  • CNNs suit images, RNN/LSTM suit sequences, transformers suit language.
  • Hyperparameters are set before training; parameters are learned.
