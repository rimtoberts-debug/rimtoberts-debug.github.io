What is AI?
Rules vs Learning

Compare programs that follow hand-written rules with programs that work out their own rules from examples.

🎓GCSE & A-Level✓Free🧩simulations + quiz
Hook

A thermostat that switches the heating on below 18°C is following a rule someone typed in. A photo app that recognises your dog in thousands of pictures is not: nobody wrote down what a dog looks like.

Both are 'smart' in everyday language, yet they work in opposite ways.

Think: Which of the two would break more easily if it met something unexpected, and why?
Explanation

Two ways to build a clever program

In rule-based programming, a person works out the logic and writes it as instructions. The same input always gives the same output, and the program only copes with situations its author thought of.

In machine learning, we supply examples and the desired answers. The computer searches for a pattern that links them, producing its own rules, usually as a set of numbers called a model.

Artificial intelligence is the broad name for systems that perform tasks we would normally link with human thinking. Machine learning is one (very successful) way of getting there.

Explanation

The learning loop

Training follows a repeating cycle: predict, compare with the right answer, then adjust. After many cycles the predictions get steadily closer to the answers.

A simple spam filter shows it well. It reads emails labelled 'spam' or 'not spam', notices that words like 'prize' appear far more in spam, and weights those words more heavily. No one typed a list of banned words.

Explanation

Why not just write more rules?

Rule lists look attractive: you can read every line and explain every decision. The trouble is coverage. Spammers change spelling, languages and tricks faster than a person can update a list, and every new rule can clash with an old one.

A learned model generalises. It does not need an exact match: if lots of spam-like words appear together, the score rises. When behaviour changes you retrain with fresh examples instead of rewriting the logic.

Explanation

Three kinds of machine learning

Supervised learning uses labelled examples (email + 'spam'). It is used for classification and for predicting numbers.

Unsupervised learning gets no labels and looks for structure itself, for instance grouping customers with similar habits into clusters.

Reinforcement learning learns by trial and error: an agent takes actions, receives rewards or penalties, and gradually favours actions that earn more reward. Game-playing and robotics systems often use it.

Explanation

When rules still win

Learning is not always the right tool. If the logic is fully known and must be exact, auditable and cheap to run, ordinary code is better. Learning shines when the pattern is too complex or too fuzzy to write down, such as recognising speech, faces or handwriting.

Explanation

Reinforcement learning vocabulary

An agent acts in an environment. In each state it chooses an action and receives a reward (positive or negative). Its aim is to maximise total reward over time, so it must balance exploration (trying new things) with exploitation (using what already works). No labelled answers are ever supplied, which separates this from supervised learning.

Summary

What to remember

  • Rule-based systems follow instructions written by people.
  • Machine learning systems derive their own rules from example data.
  • Training repeats predict, compare, adjust.
  • AI is the broad field; machine learning is one approach within it.

Exam practice

Exam-style practice

Explain one difference between a rule-based program and a machine learning model. [2 marks]

  • A rule-based program follows instructions written by a programmer (1)
  • A machine learning model finds its own patterns/rules from training data (1)

A school wants software to recognise handwritten digits. Explain why machine learning is more suitable than writing rules. [3 marks]

  • Handwriting varies hugely between people so rules would be too many/complex (1)
  • A model can learn patterns from many labelled examples (1)
  • It can generalise to new handwriting without every case being written by a programmer (1)
