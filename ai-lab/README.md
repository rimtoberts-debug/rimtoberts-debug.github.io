# AI Lab: IB CS A4 Machine learning

Eight lessons with in-browser simulations (canvas + vanilla JS, no libraries): rules vs learning, spam filter, k-means, a reinforcement-learning grid robot, line fitting, k-NN overfitting, decision trees, precision/recall thresholds, a single neuron, an XOR network, bias, data preprocessing (HL), genetic algorithms and CNN feature maps (HL). Plus an A4.1 coverage map.

Original content adapted from the owner's "Worksheet coding/clone" lessons. Its text does not match the CodeBash source pages (checked with 8-word phrase matching). Branding, external fonts and icon fonts were removed for ApexIB.
