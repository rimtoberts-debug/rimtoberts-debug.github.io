Classification and
Decision Making

See how models sort things into categories, how a decision tree reaches an answer, and why different mistakes cost different amounts.

🎓GCSE & A-Level✓Free🧩simulations + quiz
Hook

A hospital system flags scans as 'needs a closer look' or 'looks fine'. Missing a real problem is far worse than raising a false alarm, yet both are errors.

Classification is about choosing categories, and also about living with the mistakes.

Think: Would you rather a smoke alarm sometimes went off for toast, or sometimes stayed silent in a fire?
Explanation

What classification means

Classification means assigning an item to one of a fixed set of categories, such as spam / not spam. This differs from regression, which predicts a number such as a house price.

A decision tree is a simple classifier: a flowchart of yes/no questions about features, ending in a category at each leaf. It is easy to follow and explain.

Explanation

Counting mistakes

A false positive is flagging something that is not really there (a healthy scan marked as a problem). A false negative is missing something that is there (a real problem marked healthy).

Which is worse depends on the situation, so designers often tune a model to avoid the more costly kind, accepting more of the other.

Explanation

How a tree chooses its questions

A tree is built by repeatedly asking: which question splits these examples into the purest groups? A group is 'pure' when almost all its items share one label. The best first question is the one that separates the labels most cleanly, and the process repeats inside each branch.

Left unchecked, a tree keeps splitting until every leaf is perfectly pure, which is overfitting by memorisation. Limiting depth or requiring a minimum number of examples per leaf keeps it general.

Explanation

Precision and recall

Precision asks: of everything flagged, how much was right? Recall asks: of everything that was really there, how much did we catch? Raising the alarm threshold usually raises precision and lowers recall, and vice versa.

There is no universally best balance. A cancer screening aims for high recall; a system that automatically fines drivers should aim for very high precision.

Explanation

Beyond a single tree

Many trees voting together form a random forest, which is usually more accurate than any one tree, at the price of being harder to explain. This 'accuracy versus explainability' trade-off appears throughout AI.

Summary

What to remember

  • Classification assigns categories; regression predicts numbers.
  • A decision tree is a flowchart of questions ending in an answer.
  • False positives flag what is not there; false negatives miss what is.
  • The cost of each error type depends on context.

Exam practice

Exam-style practice

Describe the difference between a false positive and a false negative in a disease test. [2 marks]

  • False positive: test says disease present when it is not (1)
  • False negative: test says no disease when it is present (1)

Explain why a hospital might accept more false positives in a cancer screening system. Describe one drawback of doing so. [3 marks]

  • Missing a real case (false negative) is more harmful than extra checks (1)
  • So lowering the threshold to catch more cases is sensible (1)
  • Drawback: more healthy people worried / extra tests, cost and time (1)
