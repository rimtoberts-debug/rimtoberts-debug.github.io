# ApexIB Labs — rimtoberts-debug.github.io

Free IB Computer Science (2025 syllabus, first exams May 2027) and GCSE CS learning tools, hosted on GitHub Pages.

## Rules
- Plain HTML + CSS + vanilla JS. No build step, no npm, no frameworks. Each page must work when opened directly from GitHub Pages.
- One folder per project: `revise/`, `tools/`, `game/`, `ia/`. Shared styles in `assets/apex.css`. Do not edit another project's folder.
- Do NOT modify the root `index.html`, `about.html`, or `ai.html` (owner's personal pages) except to add a single link to `labs.html`.
- External scripts only from cdn.jsdelivr.net with pinned versions (e.g. Pyodide). No analytics, no trackers, no cookies. Progress saved in `localStorage` only, wrapped in try/catch.
- Mobile-first, works at 360px wide, light + dark mode via `prefers-color-scheme`.
- Content accuracy: follow the IB CS guide (first assessment 2027). Topic codes A1–A4, B1–B4. Paper 1 (Theme A + case study, Section B), Paper 2 (Theme B, Python or Java). No Paper 3. No IB pseudocode — use Python and Java side by side, plus flowcharts. HL-only content must be labelled HL.
- Never copy IBO past papers or imply IB endorsement. Footer: "Not affiliated with or endorsed by the International Baccalaureate."
- Keep each session to one project. Finish with a short README.md in the project folder listing what was built and how to test it.
